## Project Information

**Project Name:** HCMIU Blood Donation - Connect the Donors

**Course:** PDM (Project Development and Management)

**University:** Ho Chi Minh City International University (HCMIU)

**Developer:** Le Hoang Quoc Anh

**Academic Year:** 2024

---

## Project Purpose

The HCMIU Blood Donation website was developed to:
- Connect blood donors with recipients in need
- Raise community awareness about the importance of blood donation
- Create an effective platform for managing blood donor information
- Support blood donation campaigns at HCMIU and the community

## Technologies Used

### Frontend Framework & Libraries:
- **HTML5** - Website structure
- **Tailwind CSS** - Modern CSS framework
- **JavaScript** - Interactions and dynamics
- **Google Fonts (Poppins & Roboto)** - Professional typography

### Design Features:
- **Responsive Design** - Compatible with all devices
- **Modern UI/UX** - Contemporary user interface
- **Smooth Animations** - Fluid effects and transitions
- **Glass Morphism** - Frosted glass effects
- **Gradient Backgrounds** - Beautiful gradient designs
- **Card Hover Effects** - Interactive card animations
- **Fade-in Animations** - Smooth content reveal

## Color Scheme

**Primary Colors:**
- Red (#dc2626, #991b1b) - Main brand color, represents blood and vitality

- Light Red (#fef2f2, #fee2e2) - Backgrounds and highlights

## Installation & Setup

### Prerequisites:
- Web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, etc.)
- Local server (optional - XAMPP, WAMP, or Live Server)

### Steps:
1. Clone or download the project files
2. Open the project folder in your text editor
3. Open `index.html` in your web browser or use a local server
4. Navigate through different pages using the navigation menu
